# 版本记录

## V1 · 2026-11-10

首个公开版本。

**内容**
- 核心配置（`config/core`）：12 个公开插件，装完即可运行
- 可选段：QQ 原生通道、语音与生图 MCP
- 工具脚本：环境体检、开机自检、看门狗
- 文档：兼容矩阵、脱敏自检

**相对内部初版（未公开）的改动**
1. 拆成「核心集 + 可选段」，避免一次性全叠导致起不来
2. 移除三个 `link:` 本地源码依赖（外部机器无源码，会导致 `pnpm install` 失败）
3. QQ 通道从主配置树里剥离，改为独立可选文件
4. 新增 `scripts/check-env.ps1`：装前校验 Node 版本、DSH 位置、端口占用
5. 新增 `docs/compatibility.md`：逐插件引擎要求 + 报错对照表
